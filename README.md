# CrowRules Entertainment Admin — 30 Pages

This repository contains the CrowRules Entertainment administrative front-end starter with 30 linked pages and shared assets.

## Pages

Command Center, Notifications, Activity, Content, Episodes, Shows, Media Library, YouTube, Live Events, Members, Creators, Collaborators, Staff & Volunteers, Podcasters, Dream Library, Dream Projects, Creative Rooms, Agreements & Rights, Earnings, Pitch Room, Sports, Podcasting, Universal TV, Yearbooks, Records, Studios, Spectrum Awards, CrowSpace, Business & Finance, and Analytics.

## Structure

- `*.html` — 30 admin pages
- `assets/admin.css` — shared dark cinematic UI
- `assets/admin.js` — shared navigation and page rendering

## Security

This is a front-end starter. Connect privileged operations through authenticated Supabase Edge Functions and Row Level Security. Never expose a Supabase service-role key in browser JavaScript.

## Deployment

The repository is ready for GitHub Pages when Pages is enabled for the `main` branch.
