Recovery States

REQUESTED

A recovery flow has been initiated.

VERIFICATION_PENDING

The required verification step has not yet completed.

COMPLETED

The documented recovery process completed successfully.

EXPIRED / INVALIDATED

The recovery credential or flow can no longer be used.

Evidence Confidence

VERIFIED

Direct authoritative evidence supports the recovery finding.

SUPPORTED

Multiple relevant sources support the finding.

PROPOSED

A possible recovery difference requires validation.

UNKNOWN

Evidence is insufficient for a reliable conclusion.

Recovery Trust Boundary

PROOF Recovery should require the authentication system's approved proof-of-control mechanism; possession of unrelated profile data is not proof of identity.

TOKEN Recovery links and tokens are security-sensitive credentials and should not be stored as ordinary audit payloads.

EXPIRY Recovery credentials should have explicit expiration and invalidation behavior.

RATE Rate controls should be reviewed as documented security controls, not inferred from isolated events.

SERVER Sensitive recovery validation and account changes should occur through the trusted authentication boundary.

AUDIT Record safe event metadata, timestamps, source, and review context while minimizing personal and credential data.

Critical Guardrails

RECOVERY REQUEST ≠ ACCOUNT TAKEOVER
A recovery request or unusual recovery event does not by itself establish unauthorized access, account takeover, or malicious intent.
VERIFICATION METADATA ≠ VERIFICATION SECRET
Audit systems should retain safe metadata about verification events, never raw recovery tokens, verification codes, passwords, or sensitive links.

Safety & Platform State

V214 is an audit and governance surface. It does not reset passwords, verify accounts, issue recovery tokens, alter authentication settings, lock accounts, change rate limits, or modify identity providers. It does not trigger recovery, notifications, or deletion. No service-role credentials are exposed and no new Edge Function is deployed; the current project function-capacity limit remains respected.
