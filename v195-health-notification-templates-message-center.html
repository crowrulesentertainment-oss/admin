Supported Variables

{{service_name}} · service display name

{{service_key}} · stable service identifier

{{severity}} · watch/degraded/critical/recovery

{{incident_id}} · incident reference

{{detected_at}} · detection timestamp

{{status}} · current lifecycle status

Templates should treat these values as data, not executable content. Unknown variables should fail safely rather than exposing internal credentials or implementation details.

Message Governance

Audit: rendered-message metadata can be recorded without storing unnecessary sensitive content.
